# 分子三维查看器 · 0.2.2

## 两个入口

1. **DSH 插件（优先）**：侧栏新增「分子三维」。已有结构文件可通过文件预览打开；智能体可使用 `molecule_open({path, title?, frame?})` 请求打开。工具只返回 queued，真正读取和显示发生在当前会话 GUI，未激活或未登录不能宣称已显示。
2. **完全离线备用**：解压离线包后双击 `index.html`，手动选择/拖入结构文件或粘贴完整 XYZ。保留同目录的 `app.js`、`parsers.js`、`styles.css` 和 `vendor/`，无需网络、DSH、Python 或新服务器。

## 支持范围

- XYZ / 连续多帧 XYZ：已有笛卡尔坐标，默认 Å；额外 extended-XYZ 列不解释。
- MOL/SDF **V2000**：保留明确键及键级；V3000、查询键等会明确拒绝。平面坐标不自动转成 3D。
- PDB：ATOM/HETATM、多 MODEL、CONECT；每个残基只保留一组一致 altloc（A 优先），occupancy 不是热力学权重。不是 CIF/晶体精修工具。
- Gaussian：笛卡尔 GJF/COM；LOG/OUT 中 Input/Standard orientation 多帧坐标；FCHK/FCH 的原子序号与 Current cartesian coordinates 数组（严格核对 N/3N，Bohr → Å）。Z-matrix、Link1 多作业、ONIOM 扩展行和二进制 CHK 需先另行转换/拆分。
- ORCA：INP 中明确的 `* xyz` 或 `%coords` 笛卡尔块；LOG/OUT/OUTPUT 中 ANGSTROEM/ANGSTROM/A.U. 多帧坐标块。支持明确 Bohr 单位并换为 Å；`xyzfile` 外部引用不会被隐式读取，须另外提供坐标文件。
- 输出最后一帧 **不等于最后收敛结构**；只有明确优化标记会记录在对应前一坐标块。不推断能量、频率、极小点或 TS。

## 默认简洁模式

主界面只显示简短中文来源、原子 / 帧数和连接类型。技术字段、原始帧注释与详细限制说明默认收起，点击「坐标与来源详情」查看；未收敛标记、部分记录未解析、显示降级和文件联动错误仍保留醒目提示。保留已接受的简洁展示；新增格式解析与轨迹控制不改变输入坐标、连线或测量算法。

## 日常控制

球棍 / 棒状 / 空间填充，隐藏氢，原子编号，旋转/缩放/复位，切换构象帧，点选距离/角度/二面角，导出当前视角 PNG。

优化日志可以读取全部坐标帧、选择最后帧或明确收敛标记帧，并以 1/3/6 帧每秒播放/暂停；明确的 Gaussian Step number / ORCA optimization cycle 才显示优化步号。轨迹按原文件坐标块顺序显示，保留重复块和原参考坐标系，不作对齐、不视为 MD 物理时间；隐藏页面、切换帧/文件或到达末帧时停止。可导出本帧 XYZ，原子顺序与坐标保留，但键级、同位素及逐原子属性不保留。切换文件或帧会清空测量；UI 编号从 1 开始，内部键索引从 0 开始。

文件中给出的键优先；MDL 芳香键类型 4 保留在源解析数据中，画面仅以单线示意，不作 Kekulé 键级指派。XYZ 等无拓扑文件的连线只是一种距离示意，可关闭，不是确定键级、价态或化学结构鉴定。

## 安全与资源边界

- 只查看提供的坐标；不编辑、嵌入、加氢、优化或运行量化，不上传结构。
- 32 MiB / 文件；最多 10,000 原子 / 帧、500 帧；已打开文件累计最多 100,000 原子坐标。超过限制请先截取目标结构，不能绕过 DSH 文件限制。
- 智能体排队时将相对路径绑定到当时的权威工作目录；拒绝 URL 和网络共享路径。
- DSH 文件读取复用其 sandboxed `sidebar/api/fs.read`。插件新路由只允许预定义静态资源和会话打开请求，不提供任意文件读取接口。
- iframe 消息必须来自同源父页面；file:// 的不透明来源禁用消息桥，但手动文件选择仍可用。
- UI 数据仅存内存，关闭页面释放；没有 localStorage/云端保存。
- 固定本地 3Dmol.js 2.5.3，完整第三方许可证随包保留。

## 安装与回退

下载 GitHub Release 中的预构建 TGZ，无需安装期构建脚本：

```bash
dsh plugin add https://github.com/Zoanthamine/dsh-molecular-viewer/releases/download/v0.2.2/dsh-molecular-viewer-0.2.2.tgz
```

需要 DSH 0.2.2-rc.2+、dsh-better-sidebar 0.32.1 API 和 Node 22+。安装后刷新原 DSH 页面，打开侧栏「+ → 分子三维」。登录由用户正常完成；插件不绕过宿主认证。禁用/移除此 bundle 可回退；離线 ZIP 解压后双击 index.html。

公开仓库只包含插件代码、许可证及合成测试，不包含真实计算文件、个人路径或科研目录历史。0.2.2 修复 Chem3D 风格 PDB 中无 altloc、却重复使用原子名称时的误去重：保留不同原子序号及明确 CONECT 连线；真正的替代位置仍只在对应原子位点选择。公开回归测试全部使用合成数据。


## Agent 联动

`molecule_open` 的 `frame` 支持 `all`（默认首帧并保留整条轨迹）、`first`、`last`、`last-converged` 或从 1 开始的帧号字符串。不存在明确收敛标记时，`last-converged` 必须报错，不回退到最后帧。需要先检查或提取时，通过已授权的宿主执行工具运行随插件提供的 `lib/extract-coordinates.mjs`；只返回格式、原子/帧数、收敛证据及哈希摘要，不在对话粘贴完整坐标。指定 `--output NEW.xyz` 才写新文件，拒绝覆盖原文件或既有输出。详见同目录 `AGENT-INTEGRATION.md`。

这里兼容的是 Gaussian `.gjf` 输入。真正 `.gif` 是图像/动画，不能可靠地还原笛卡尔坐标；本次不把它或二进制 `.chk` 伪装成坐标格式。

## 可复用方式

下次直接说：「打开这个 XYZ 看三维」「切换这个 SDF 的构象」「测这四个原子的二面角」。不必在聊天中粘贴大量坐标；给文件路径即可。插件不会把坐标全文回传到对话，避免再次膨胀上下文。
